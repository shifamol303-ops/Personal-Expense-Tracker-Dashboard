# Personal-Expense-Tracker-Dashboard
An interactive Personal Expense Tracker Dashboard built using Microsoft Excel to analyze income, expenses, spending categories, and monthly financial trends. Features KPI cards, charts, a treemap, and interactive month filters for better expense tracking and financial insights.
# Personal Expense Tracker Dashboard

## Project Overview
The Personal Expense Tracker Dashboard is an Excel-based data visualization project designed to analyze personal income and expenses. It provides a clear overview of spending patterns, expense categories, and monthly financial trends through interactive charts and visual summaries.

## Key Features
- Summary cards for major expense categories.
- Monthly expense filtering using a slicer.
- Spending analysis by category.
- Income and expense comparison.
- Monthly net income versus expenses analysis.
- Treemap visualization of expense categories.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

## Project Objective
The main objective is to make personal financial tracking easier by organizing financial data and presenting meaningful insights in a single dashboard.

## Key Insights
The dashboard helps identify major spending categories, compare income with expenses, and explore monthly changes in financial activity.

## Conclusion
This project demonstrates how Microsoft Excel can be used to transform financial data into an interactive dashboard. It helped develop practical skills in data analysis, reporting, and dashboard design.
